# M&B Maps — репозиторий карт Supreme Commander: Forged Alliance

Хранилище карт для лаунчера. Архивы карт (`.zip`) хранятся как **обычные файлы git**
(без Git-LFS), каталог `index.json` и миниатюры `previews/` — рядом.

> LFS на репозитории отключён, поэтому архивы НЕ должны проходить через Git-LFS.
> Убедитесь, что в `.gitattributes` нет строк `filter=lfs` для `*.zip`.

## Структура

```
M_B_Maps/
├─ .gitattributes         # без LFS (архивы — обычные файлы)
├─ index.json             # каталог всех карт (см. схему ниже)
├─ previews/<id>.png      # миниатюры ~256px
└─ maps/<папка>.zip       # архивы карт (обычные файлы git)
```

## Схема index.json

```json
{
  "version": 1,
  "updated": "2026-07-17",
  "maps": [
    {
      "id": "5_minut",
      "name": "5 minut",
      "description": "...",
      "size": "1024 × 1024",
      "players": 8,
      "mapVersion": 2,
      "fileSize": 3229021,
      "sha256": "ba2854c041780bac757a31ee6134e84919a14ddf85ddc0e697d063f5b1279669",
      "preview": "previews/5_minut.png",
      "archive": "maps/5_minut.v0002.zip"
    }
  ]
}
```

- `id` — стабильный идентификатор = имя папки карты без версии.
- `mapVersion` — число из суффикса версии (например `2` для `.v0002`).
- `sha256` — SHA-256 архива (контроль целостности при скачивании).
- `fileSize` — размер архива в байтах.
- `preview` — путь к миниатюре внутри репо.
- `archive` — путь к архиву внутри репо.

## Как добавлять карты

**Простой способ — через лаунчер:** в окне менеджера карт → «Подготовить карту»
(или ПКМ по установленной карте → «Подготовить для репозитория»). Лаунчер сам
упакует карту в `.zip`, посчитает `sha256`/`fileSize`, создаст миниатюру и
обновит `index.json`. После этого:

```bash
git add -A
git commit -m "Add 5_minut"
git push
```

Важно: `MapVaultConfig.LocalRepoPath` в лаунчере должен указывать на эту
локальную копию репозитория.

## Обновление карты

Увеличьте `mapVersion`, положите новый архив `maps/<папка>.v000N.zip`,
пересчитайте `sha256`/`fileSize`, обновите запись в `index.json`, закоммитьте.
Лаунчер сверяет `mapVersion` + `sha256` с локальным манифестом и помечает карту
как «Доступно обновление».

## О размере репозитория

Архивы — обычные файлы git, поэтому репозиторий растёт по сумме размеров всех
карт (~1.7 ГБ на полную коллекцию). Это допустимо: отдельные файлы < 100 МБ
(лимит GitHub), а пользователи ничего не клонируют — лаунчер тянет каждый архив
по прямой ссылке (`raw.githubusercontent.com`). GitHub присылает уведомление о
крупном репо при > 1 ГБ и блокирует при ~5 ГБ.

Если коллекция вырастет до нескольких ГБ — перенесите `archive` на **GitHub
Release assets** (до 2 ГБ на файл, CDN, не пухлит git-историю): достаточно
поменять путь/URL в `index.json` и сборку URL в `MapVaultConfig`, клиент
менять не нужно.
